# Nykaa Beauty Analytics Dashboard

## Project Overview
This project analyzes customer purchasing behavior, revenue trends, category performance, and customer retention using SQL and Power BI.

## Tools Used
- SQL (MySQL)
- Power BI
- Excel

## KPIs
- Revenue
- Lost Revenue
- Repeat Customer %
- Average Price Value

## Dashboard Features
- Revenue by Category
- Revenue by Gender
- Revenue by Age Group
- Top Brands
- Premium vs Non-Premium Analysis
- Monthly Revenue Trend
